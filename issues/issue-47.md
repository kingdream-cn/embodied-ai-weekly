## 📚 精选教程 & 学习资源

::: card tutorial
### 1. [具身感知入门：机器人如何“看”世界](https://www.bilibili.com/video/BV11cuA6rE5a/)

- **核心亮点：** 这段约 5 分钟的入门视频介绍相机、激光雷达、力与触觉等感知方式，帮助理解机器人如何形成环境观测和交互反馈。适合建立整体概念，不作为具体感知算法的性能评测。
- **团队参考：** 用团队当前任务画一张“传感器—观测量—决策—反馈”表，明确哪些状态能直接观测，哪些需要融合估计，可用于新人入门讨论。
- **载体：** 视频 / 5分06秒 / 入门资源
:::

::: card tutorial
### 2. [LeRobot + LingBot-VLA：从模型接入到机械臂实操](https://www.bilibili.com/video/BV1oUVG6NEZi/)

- **核心亮点：** 这段约 33 分钟的视频围绕 LeRobot 机械臂改造和 LingBot-VLA 上手实践展开，适合梳理图像、状态与语言指令如何连接到动作执行。视频用于学习接入流程，单次演示不代表模型在新场景中的泛化能力。
- **团队参考：** 先复现一个抓取或放置任务，固定权重、依赖、相机与动作接口并保存失败日志；跑通后再改变物体位置、光照和指令，比较成功率与失败类型。
- **载体：** 视频 / 33分09秒 / 实操教程
:::

::: card tutorial
### 3. [NVIDIA Holoscan 5：用重力补偿回路检查控制时序](https://developer.nvidia.com/blog/make-a-robot-arm-feel-weightless-with-nvidia-holoscan-5/)

- **核心亮点：** NVIDIA 官方教程用 Holoscan 5、Pinocchio 与机械臂搭建“读取关节—计算重力补偿—输出力矩”的控制回路，并讨论调度、队列、CPU 绑定和性能观测。示例的 400 Hz 设置不等于任意硬件都能满足同样时序。
- **团队参考：** 在现有平台先记录回路延迟、尾部抖动与过期样本处理，再比较线程组织和队列策略；用测量结果判断瓶颈是否来自通信、调度或动力学计算。
- **载体：** 官方代码教程 / Python 与 C++ / 2026-11-09
:::

## 🛠️ 开源项目 & 行业案例

::: card opensource
### 1. [开发工具｜TokenEconomizer：减少编码智能体的重复成本](https://github.com/microsoft/TokenEconomizer)

- **核心亮点：** 微软与 UC Berkeley 的 TokenEconomizer 从历史会话提炼可复用经验、裁剪闲置工具，并干预重复失败循环。项目报告 SWE-bench 五组模型配置的平均成本下降 18.4%—30.9%，属于编码智能体实验，不是机器人控制效果。
- **团队参考：** 作为团队开发工具补充，在固定代码任务集上同时记录费用、通过率和人工返工时间，再判断经验复用是否有效；不要只追求单次 token 消耗降低。
- **载体：** GitHub 开源仓库 / 编码智能体工具
:::

::: card opensource
### 2. [酒店洗衣机器人：云端规划、端侧技能与失败回流](https://www.qbitai.com/2026/11/509203.html)

- **核心亮点：** 酒店洗衣机器人案例把仿真训练、云端任务规划和端侧技能执行串联起来，通过调度、执行反馈与失败回流迭代技能，并保留版本回滚。报道中的“30 分钟降至约 18.6 秒”使用厂商给定任务口径，不包含洗涤和烘干的完整周期。
- **团队参考：** 借鉴技能拆分、失败记录与版本回滚机制；比较效率时固定任务边界、设备条件、人工介入和恢复时间，避免混用不同流程的耗时。
- **载体：** 应用案例报道 / 非开源仓库 / 2026-11-11
:::

::: card opensource
### 3. [回顾｜World Labs R2S2R：用真实任务构建可控仿真](https://worldlabs.ai/blog/real-to-sim-to-real)

- **核心亮点：** World Labs 的 SceniX 案例先把真实机器人、物体与交互重建为可控仿真，再改变物体配置、视角与物理属性训练策略，并用仿真筛选策略、定位真实失败区域。其“零真实世界训练数据”指策略训练，任务重建仍需现实采集；这是 2026 年 7 月的研究案例回顾。
- **团队参考：** 从一个操作任务开始，用相同开环动作核对仿真与实物响应，再比较多个策略在分布内和分布外条件下的相对排名，判断仿真能否辅助筛选模型、暴露失败与安排真机评测。
- **载体：** 仿真训练与评测案例 / 非开源仓库 / 往期回顾
:::

## 📑 顶会前沿 & 论文速递

::: card paper
### 1. [Pixel：把硬件、示范采集、全身控制与策略学习一起设计](https://arxiv.org/abs/2611.03648)

- **核心亮点：** CMU 的 Pixel 论文把轮式机器人硬件、示范采集、全身控制和策略学习联合设计：对齐人机视角与夹爪几何，统一人类和机器人示范的动作空间，再用高层视觉语言规划与低层动作策略完成移动操作。研究包含硬件、数据接口和策略学习评估；项目代码尚待公开。
- **团队参考：** 重点比较三种遥操作接口与无机器人示范采集方式，检查相机视角、夹爪结构和动作空间是否对齐；再研究统一控制器如何衔接导航、双臂操作与长程子任务，避免只替换策略网络。
- **载体：** 研究论文 / arXiv 2026-11-02 / 代码待公开
:::

::: card paper
### 2. [Praxis-1：从视频预训练到机器人动作控制](https://runway.com/research/praxis-1-video-pretraining-to-robot-control)

- **核心亮点：** Runway 的 Praxis-1 技术报告研究如何把视频预训练迁移到机器人控制：视频主干预测未来场景，动作专家读取视频特征，机器人专属投影连接不同本体的状态与动作。训练保留视频预测并联合学习动作，报告对比了迁移、动作误差和推理设置，权重与微调代码已公开。
- **团队参考：** 重点读架构、分阶段训练和错误分析：对照预测视频中的目标选择与实际动作偏差，判断错误来自视觉预测还是控制；再比较整块执行与实时分块对连续性、延迟和任务成功率的影响。
- **载体：** 官方技术报告 / 2026-11 / 附开放权重与代码
:::

::: card paper
### 3. [FAFM：用频域流匹配处理混合控制频率的示教数据](https://arxiv.org/abs/2606.20135)

- **核心亮点：** FAFM（Frequency-Aware Flow Matching）把离散动作块映射为 DCT 频域系数，在系数空间做流匹配，再重建连续动作轨迹，并用时间导数约束平滑性。方法面向不同控制频率示教数据共同训练，原论文于 11 月 9 日更新。
- **团队参考：** 若团队存在不同采样频率的数据，可在同一任务上比较频域表示与重采样基线，同时记录任务成功率、动作平滑度及推理延迟，检查时间一致性是否真正改善。
- **载体：** 原始论文 / arXiv v2 2026-11-09
:::
